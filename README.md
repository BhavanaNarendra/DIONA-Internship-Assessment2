DIONA Internship Assessment 2

A structured ODK XLSForm developed for Criminal Risk Assessment requests.

Project Overview

This project transforms a traditional paper-based Criminal Risk Assessment Request into a structured digital form. It focuses on organized data collection, accuracy, validation, and ease of use.

Key Features

- Structured Consent & Authorization section
- Personal Information and Identification sections
- Required-field validation
- Minimum two-piece identification check
- Conditional input for other identification
- Date validation
- Phone and email format validation
- Digital signature support
- Automatically displayed person's name on the second page

Form Structure

The form is organized into:

1. Consent & Authorization
2. Personal Information
3. Identification
4. Risk Assessment Details
5. Request and Designate Information

File

Validation
